# `.MAT` — CONFIRMED structure
`u16 count, u16 version(=1)`, `count × 46 B`:
`+0 char name[16]` · `+0x10 u8 palStart` · `+0x11 u8 palEnd` (shade ramp; flat surfaces use `start + (end-start)*light`) · `+0x12 u8 ?` · `+0x13 s8 ?` · `+0x14/0x15 s8 ?` · `+0x16,0x18,0x1A,0x1C u16 ?` · `+0x1E u16 shift (ramp end adjusted by (1<<shift)-1)` · `+0x20 u16 (unused)` · `+0x22 char pattern[12]` texture file pattern or empty.
Loaded as track MAT then `CARS.MAT` (ship materials). Material numbers are global indices into that concatenation; shapes/TRC refer to them by **name** via their own `(name,id)` tables. Remaining unknown: `+0x14` (s8 -> runtime +0x18): when it is 0 the polygon is drawn with render flag 0x10, which selects the other pair of span routines (0x30600 / 0x2DC2F instead of 0x30E48 / 0x308E2, 0x1AECA..0x1AF08); which variant is the transparent one was not decoded. `+0x15` (runtime +0x1A) is the flag the port already uses (non-zero: skipped by the track-load transparency test 0x1A3D5).

## Fields decoded — CONFIRMED (Draw3DSetMaterials 0x18E36..0x18EA1, lighting 0x1C4B6/0x1CCE9/0x1A1C8)
`+0x12` u8 → fallback colour (used when "ramp colour − 1" would fall below the ramp, 0x1A98C) · `+0x13` s8 → Gouraud/vertex-normal flag (Dummy = 1; the per-vertex path 0x1BAC6) · `+0x16` u16 **fixed brightness** (2.14; non-zero ⇒ ramp position = this value, no lighting) · `+0x18` u16 **ambient coefficient** · `+0x1A` u16 **diffuse coefficient** · `+0x1C` u16 **specular coefficient** (all 2.14) · `+0x1E` u16 shift (ramp end = start + min(end−start, 0x70) − ((1<<shift)−1)).
Flat shade (ramp position 0..0x4000): fixed ≠ 0 → fixed; all of ambient/diffuse/specular 0 → `level + ambient` (= 0x3FFF with the track setup below, i.e. the top of the ramp); else `ambient·A + diffuse·(max(0, n·(−L))·D)` (+ specular·0 — the polygon path passes no specular term). Colour index = start + ((end − start)·shade >> 14).
Global lighting (set for every track by 0x595DD–0x595F1 → `TrackSetCameraRange`): light direction L = (0, −1, 0) (straight down, world space), diffuse level 1.0 and ambient 0.25 normalised to a sum of 1.0 (`0x1958F`: D = 0x3333, A = 0x0CCC), depth-cue fog disabled (`0x595F1 → 0x195F1(0)`), far distance unlimited except Tokyo (0x260000, via the per-track hook table at 0x595F8).
