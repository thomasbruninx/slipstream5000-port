# GDV (Gremlin Digital Video): INTRO.GDV, LOGO_S.GDV

Loose files next to the executable (not in the RES archives). Port: `src/original_formats/gdv.{hpp,cpp}`, test `tests/gdv_tests.cpp` (decodes both files; frame 100 of INTRO.GDV is bit-identical to FFmpeg's `gdv` decoder, checked with `SLIP_GDV_DUMP`). Labels: CONFIRMED by that comparison unless noted.

* Optional text banner: LOGO_S.GDV starts with a 0x30 byte banner ("GDV Format (C) Gremlin Interactive 1994/95") + one zero dword; the header proper starts at 0x34.
* Header (little endian): magic `0x29111994`, u16 size id (0: 320x200, 1: 640x200, 3: 320x180 ...; used when width / height are 0), u16 frame count, u16 fps, u16 sound flags (1 = audio, 2 = stereo, 4 = 16 bit, 8 = Gremlin DPCM), u16 sample rate, u16 depth flags (1 = palette follows), 4 bytes unknown, u16 width, u16 height, then 256 x RGB (6 bit) when the palette flag is set. INTRO.GDV: 320x180, 385 frames at 12 fps, 22050 Hz 8 bit mono (32 s). LOGO_S.GDV: 640x200 id 1, 82 frames at 9 fps.
* Per frame: the audio chunk (`rate / fps` bytes; LOGO_S.GDV stores 2 bytes more per frame after the first, the reader re-synchronises on the next marker) then the video chunk `u16 0x1305, u16 size, u32 flags, data[size]`.
* Video chunk flags: low nibble = method (0 palette only, 1 clear + palette, 2, 3 no change, 5, 6, 8 = LZ77 style delta coders working on a persistent frame buffer with a 4096 byte preamble that backward / forward copies may reach into), bits 8.. = number of leading bytes to keep unchanged, bits 4 / 5 = half-size coded frames (never seen in the game's movies; not ported).
* LOGO_S.GDV is the Gremlin flag animation. Its frames use method 2 with a u16 in front of the tag stream (the stream then covers exactly 320x200 pixels; FFmpeg cannot decode it) and its header says size id 1 (640x200) while the frames are 320x200. LOGO.EXE is the same GDV player as PLAYGDV.EXE. The Software Refinery logo with the textured ball is the game's own credits screen (docs/frontend.md).
